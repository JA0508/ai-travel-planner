# Project Overview

## AI Trip Compiler / Executable Trip Workspace

本项目是一套面向真实旅行场景的 **AI 行程编译与执行系统（AI Trip
Compiler）**，旨在解决用户在旅行规划过程中“信息过载但无法形成可执行
计划”的问题。

旅行用户通常从小红书、短视频、朋友推荐等渠道收集大量碎片化兴趣点，但
这些内容缺少时间安排、空间关系和个人约束的整合，最终仍需要用户手动规划
路线。

系统通过 **LLM 驱动的意图理解层** 与 **确定性规划执行层
（Deterministic Planning Engine）**，将用户自然语言输入、收藏地点、餐饮
偏好、预约事项、出行时间窗口等非结构化信息转换为结构化旅行意图。系统
能够识别用户的必去地点、可调整地点、固定时间安排、偏好倾向以及限制
条件，并进一步结合空间距离、停留时长、交通衔接和每日节奏，生成可执行的
Trip Skeleton（行程骨架）。

与传统 AI 旅行助手“一次生成完整攻略”的方式不同，本系统强调 **用户意图
优先（Intent-first）** 和 **可控规划（Controllable Planning）**：用户提供
的核心需求始终保持优先级，固定预约和重要地点不会被模型随意修改；对于
信息不足或时间存在空档的情况，系统会基于当前路线、时间窗口和用户偏好
自动补充合适的 POI、餐饮节点以及过渡安排，使用户无需提前完成复杂规划，
也能够快速获得合理的初版路线。

在行程调整过程中，系统支持局部修改而非整体重生成。用户可以替换某个
景点、删除不喜欢的安排、锁定重要节点；系统会基于新的用户反馈更新旅行
意图，并通过确定性规则重新计算受影响部分，避免传统 AI 生成结果不可控、
修改困难的问题。

系统的规划解释层会记录每个安排产生的原因，包括为什么选择该地点、为什么
放置在该时间段，以及哪些约束影响了最终路线，使旅行计划不仅“看起来合理”，
更具备可理解性和可信度。

未来，系统将进一步结合真实地图服务、POI 数据、用户历史偏好以及实时旅行
信息，实现更智能的个性化规划能力，让旅行规划从“搜索攻略 + 手动拼接”的
过程，转变为“表达想法 → 自动生成 → 用户调整 → 持续优化”的智能旅行工作流。
